# Definitions
- *Target unit*: the unit that the user on the game page has the find.
- *Guessed unit*: the unit that the user guessed on an attempt

---

# Columns

- Unit name
- Traits
- Abilities (Kb, slow, weaken, immune to waves, etc.)
- Attack type (Single, Area, LR, Omni)
- Cost
- Form (normal, evolved, true, ultra)
- Rarity (Normal, Special, Rare, Super Rare, Uber Rare, Legend Rare)
- Talents (if the target unit has some)

# Hints
To help the player find the correct unit.

## When 8+ guesses

if the target unit is from a collab, then display the collab's name
else, display that it's not a collab unit

## When 10+ guesses

if obtained in gacha, display the gacha banner name

else, display if obtained in:
- story mode (EoC, Future w/ aliens, CotC, Aku realms, Labyrinth, Zombie outbreak)
- Advent stage (ex: Realm of Carnage, etc.)
- SoL
- UL
- ZL
- Collab stage
- Awakening stage
- Other stage (ex: Growing strange, etc.)

## When 12+ guesses

Give the first sentence of the description

### When 15+ guesses

Give the whole descrption

### When 18+ guesses
Give 1-3 letters of the name, depending on the length of the target unit.
